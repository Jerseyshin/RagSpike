# 法规文档清单

本目录保存中国大陆隐私、数据安全、App 与移动终端合规语料的文档清单，不保存未经确认的抓取正文。

## 文件约定

- `documents.jsonl`：每行一个文档版本，字段遵循 `schemas/document-manifest.schema.json`。
- `unresolved-requests.jsonl`：保存曾经无法唯一识别或需要审核人确认的原始条目及其处理结果，防止截断标题被静默遗漏。
- `snapshot.json`：语料快照版本、文档数量和整体哈希，在正式冻结语料时生成。
- 一个 `document_id` 只对应一个明确版本；修订版必须创建新条目，不能覆盖旧版本。

## 来源要求

首选来源顺序：

1. 全国人大及其常委会官方站点。
2. 中国政府网、国务院公报。
3. 国家互联网信息办公室及其他正式发布机关。
4. 国家标准全文公开系统或全国标准信息公共服务平台。
5. 全国网络安全标准化技术委员会、电信终端产业协会等标准发布组织官网。
6. 最高人民法院、最高人民检察院等正式司法机关站点。

新闻转载、商业法律数据库、博客和搜索结果页不能作为语料正文的最终来源；它们只能用于发现候选文件。

## 收录状态

```text
candidate -> source_verified -> downloaded -> normalized
                   |
                   -> excluded
```

进入正式语料快照前，条目必须满足：

- 官方来源已验证。
- 发布和生效日期已验证。
- 当前效力及版本关系已验证。
- 收录范围和理由已审核。
- 下载正文已计算 SHA-256。
- `review_status` 为 `approved`。

## 效力与版本标记

- `current`：当前有效或当前可用版本。
- `future`：已发布但尚未到实施日期。
- `superseded`：已被新版代替，仅用于历史或版本差异问题。
- `historical`：专项行动期等已结束，但仍有历史研究价值。
- `draft`：征求意见稿或公示稿，绝不能作为现行义务直接回答。

推荐性国家标准、行业标准、地方标准、团体标准和技术指南不得因名称中含“要求”“规范”而自动推断为法律强制义务。
